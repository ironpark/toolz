## Initializing

When you first read this `AGENTS.md` for a task, run the following command once from the directory containing this file, before making any changes:

```sh
./scripts/gitwt-ctx status
```

Follow exactly one rule based on the reported `STATUS`:

- `SKIP`: Do Nothing
- `MISSING`: Read and follow `docs/agents/worktree/MISSING.md`.
- `INVALID`: Read and follow `docs/agents/worktree/INVALID.md`.
- `READY`: Read and follow `docs/agents/worktree/READY.md`.
