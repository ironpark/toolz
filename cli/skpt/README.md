# skpt

`skpt`(skill point)는 에이전트 스킬을 한 번 정의한 뒤 Claude Code, Codex 및
Agent Skills 호환 도구에 최적화된 플랫폼별 스킬로 컴파일하는 CLI입니다.

플랫폼마다 별도의 `SKILL.md`를 관리하는 대신 스킬의 의도, 작업 흐름, 리소스와
실행 요구 사항을 공통 소스에 기록합니다. `skpt`는 이 소스를 각 대상 플랫폼의
기능과 관례에 맞는 결과물로 변환합니다.

> [!NOTE]
> 현재는 프로젝트의 Go 기반과 CLI 진입점만 준비된 초기 개발 단계입니다.
> 스킬 소스 형식과 컴파일 명령은 이후 구현할 예정입니다.

## 목표

- 하나의 공통 소스를 여러 에이전트 플랫폼에서 재사용합니다.
- 각 플랫폼의 기능과 제약을 반영한 결과물을 생성합니다.
- 생성 과정을 반복 가능하게 만들어 플랫폼별 스킬의 차이와 중복을 줄입니다.
- 스킬의 의도와 실행 요구 사항을 결과물과 분리해 유지합니다.

## 개발

Go 1.24 이상이 필요합니다.

```sh
go test ./...
go run . --version
```

실행 파일은 다음과 같이 빌드할 수 있습니다.

```sh
go build -o bin/skpt .
```
