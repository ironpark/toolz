# spona

`spona`는 코딩 에이전트의 실행 환경을 프리셋으로 저장하고 재현하는
CLI입니다. Claude Code, OpenCode, Codex 등의 하네스와 시작 모델, 스킬,
MCP 서버, `AGENTS.md` 같은 에이전트 지침을 하나의 프리셋으로 관리합니다.

> [!NOTE]
> 현재는 Go 기반과 CLI 진입점만 준비된 초기 개발 단계입니다. 프리셋 형식과
> 관리·실행 명령은 이후 구현할 예정입니다.

## 목표

- 하네스별 실행 설정과 시작 모델을 프리셋으로 저장합니다.
- 스킬, MCP 서버 및 에이전트 지침을 프리셋과 함께 관리합니다.
- 저장된 프리셋으로 일관된 에이전트 실행 환경을 구성합니다.
- 프로젝트와 작업 목적에 맞는 환경을 빠르게 전환하고 재사용합니다.

## 개발

Go 1.26.3 이상이 필요합니다.

```sh
go test ./...
go run . --version
```

실행 파일은 다음과 같이 빌드할 수 있습니다.

```sh
go build -o bin/spona .
```
