# mohae

`mohae`는 CLI, MCP 서버, 에이전트 스킬을 재현 가능한 환경에서 실행하고 비교하기 위한
테스트·평가 CLI입니다.

현재는 프로젝트 초기 골격만 제공하며, 다음 기능을 목표로 합니다.

- 초기화 스크립트, 에이전트 종류, 시작 프롬프트, `AGENTS.md`, 완료 후 검증 스크립트로 환경 정의
- 여러 환경 설정의 실행과 대화·토큰 사용량·명령 실패·검증 결과 리포트
- 에이전트 또는 MCP 서버가 사용하는 CLI의 통합 테스트
- 실행 시 프롬프트와 `AGENTS.md`를 덮어쓰거나 변형하여 A/B 테스트

## 개발

Go 1.26.3 이상이 필요합니다.

```sh
cd cli/mohae
go run .
go test ./...
go build -o mohae .
```

현재 사용할 수 있는 옵션은 버전 출력뿐입니다.

```sh
go run . --version
```
