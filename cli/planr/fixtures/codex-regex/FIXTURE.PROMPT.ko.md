패턴 매칭 도구를 하나 만들어 주시겠어요? 이 디렉터리는 비어 있으니 Go 프로젝트부터
직접 만드셔야 합니다. 모듈 이름은 `example.com/rx`로 하고, 빌드하면 `rx` 실행 파일이
나오면 됩니다.

제가 부르는 방식은 세 가지뿐입니다.

```
rx <pattern> <file>      # 매치되는 줄을 출력
rx -o <pattern> <file>   # 매치된 문자열만 한 줄에 하나씩 출력
rx -c <pattern> <file>   # 매치된 줄의 개수만 출력
```

파일을 안 주면 표준 입력을 읽습니다. 명령 표면은 이게 전부입니다.

정작 중요한 건 패턴 문법입니다. 아래를 전부 지원해야 하고, 서로 조합도 돼야 합니다.

- `.` 임의의 한 글자
- `*` `+` `?` 바로 앞 요소의 반복
- `[abc]`, `[a-z]`, `[^abc]` 범위와 부정을 포함한 문자 클래스
- `^`와 `$` 앵커
- `|` 선택
- `()` 그룹. `(ab)+`나 `a(b|c)d`가 기대대로 동작해야 합니다
- `\` 이스케이프. `\.`는 리터럴 점, `\\`는 리터럴 백슬래시

매칭은 가장 왼쪽에서 시작하고 탐욕적입니다. `aaa`에 `a+`를 걸면 `a` 세 번이 아니라
`aaa` 한 번입니다. `-o`는 그 전체 매치를 출력해야 합니다.

**매칭은 직접 구현해 주세요 — `regexp`를 import하지 마시고요.** 표준 라이브러리를 한 줄로
감싸면 부탁드린 의미가 없습니다. 그 외 표준 라이브러리는 얼마든지 쓰셔도 되고, 외부
의존성은 아예 안 들어갔으면 합니다.

동작 중에 신경 쓰이는 부분들입니다.

- 잘못된 패턴 — `a(b`, `[z-a]`, 끝에 남은 `\`, 앞에 아무것도 없는 `*` — 은 리터럴로
  처리하지 말고 stderr에 오류를 내고 0이 아닌 코드로 종료해야 합니다.
- 없는 파일도 마찬가지로 stderr에 오류, 0이 아닌 종료입니다.
- 매치가 하나도 없는 건 오류가 *아닙니다*. 아무것도 출력하지 않고(`-c`면 `0`) 0으로
  끝나야 합니다.
- 종료 코드는 매치가 있으면 0, 없으면 1, 실제 오류면 그 외의 값으로 해 주세요. 셸
  조건문에서 쓰고 싶습니다.
