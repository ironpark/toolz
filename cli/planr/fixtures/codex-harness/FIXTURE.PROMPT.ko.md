greeting CLI에 JSON 출력 모드 좀 추가해 줘.

지금은 `go run . --name Ada` 하면 `Hello, Ada!`가 그대로 찍히는데, 이걸 다른 스크립트에서
받아서 쓰려니까 문자열을 잘라 파싱해야 해서 불편해. `--format json`을 주면 JSON 한 줄로
나오게 해 주면 좋겠어. `message` 필드에 인사말만 들어 있으면 충분해.

몇 가지 부탁:

- 기존처럼 `--format` 없이 쓰면 지금 출력 그대로 나와야 해. 쓰던 스크립트가 깨지면 곤란해.
- `--format xml`처럼 지원 안 하는 값을 주면 그냥 조용히 넘어가지 말고, 뭐가 잘못됐는지
  알려 주고 종료 코드도 0이 아니게 해 줘.
- text/json 둘 다랑 잘못된 format 케이스까지 테스트가 있으면 좋겠어.
- README에 두 모드 사용 예시도 적어 줘.

외부 라이브러리는 안 썼으면 해. 표준 라이브러리로 충분할 것 같아.

작업은 중간에 나한테 물어보지 말고 끝까지 알아서 진행해 줘. 계획만 세워 놓거나 "이렇게
하면 됩니다" 정도로 멈추지 말고, 실제로 코드까지 다 고치고 테스트가 통과하는 상태로
만들어 줘. 위에 적은 것들이 전부 해결됐다고 스스로 확인이 될 때까지 계속 진행하고,
다 끝나면 뭘 어떻게 했는지 짧게 정리해서 알려 줘.
